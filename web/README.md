# AnimeVerse AI — Web preview

This is the first mobile-friendly web interface for AnimeVerse AI.

## Current preview
- Responsive anime-inspired interface
- My Story, Discover and Living World screens
- Starter adult character catalogue and local character creation
- Starter locations
- Player-led chat UI that does not pretend a live AI backend is connected

## Next milestones
1. Add a secure backend API for online model providers. Provider keys must remain server-side and must never be shipped in browser JavaScript.
2. Add authentication and persistent user/story storage.
3. Connect character-specific prompts, long-term memory summaries and group roleplay.
4. Expand the world engine with location-aware encounters, NPC goals, routines and events.
5. Add offline model support to the Android app and package this web experience for Android.

The current frontend is a prototype, not a completed AI service.
